`main.ts` writes one loading-screen tip (under the 200-character limit) to `/output/entry.txt`, deterministically:

> Your agent is waiting for you to approve the change it already made, and you're waiting for it to finish. Nobody is working.

## Run

```sh
node main.ts
cat /output/entry.txt
```
